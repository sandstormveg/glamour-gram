# Glamour Gram

Natural philosophy for the long dawn. Interactive pages about physics and wonder, and the futures we could spell into being.

- **Four Days Old**: ride an endless wave, zoom into the age of stars, and climb the ladder of wholes.
- **The Three-Letter Spell**: everything is written in three letters (up quark, down quark, electron). Learning to spell in them is the closest thing to real magic.

Plain HTML, no build step. Served with GitHub Pages from the `main` branch.
